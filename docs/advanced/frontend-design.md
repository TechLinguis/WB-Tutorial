# 一句话撸出一个能上线的页面：WorkBuddy 的前端设计技能有点东西

前阵子我想做个深色主题定价页，要是搁以前，得开 Figma、找参考、调间距，半天没了。现在我对 WorkBuddy 说一句"做个深色 SaaS 定价页，三档套餐，含月付年付切换"，它直接甩我一个能预览的 HTML。

这事靠的是前端设计技能。这篇讲清楚它什么时候出场、怎么用、以及它偷偷守着的设计底线。

## 01 什么时候该请它出手

你的需求只要沾"网页、组件、页面、落地页"，就该优先喊它：

- "帮我做个登录页、仪表盘、落地页"
- "把这个设计稿实现成代码"
- "审查下这个 UI，给改进建议"

它不只能从零造，还能对已有页面做审查和优化，这点后面会说。

## 02 两个技能，一个造一个改

frontend-design 负责创建：产出 distinctive、生产级的前端界面，强调设计质感。frontend-design-pro 是专业增强版，提供 /audit、/polish、/critique、/colorize、/animate 这些审查命令，专门规避常见反模式。

简单记：要新页面用前者，要改页面用后者。两者配合，从生成到打磨一条龙。

别小看这个分工。很多人拿 pro 版去从零造页面，属于杀鸡用牛刀；也有人拿基础版去改别人的烂页面，它又没那些审查命令。用对场景，效率差出好几倍。

## 03 五个命令，专治各种丑

pro 版这几个命令值得背：/audit 审查当前页面、列问题；/polish 在现有基础上打磨视觉与交互；/critique 给专业级批评和重构建议；/colorize 套协调配色；/animate 加合理动效。

我常用的组合是 /audit 先体检，再 /polish 微调。比自己对着屏幕瞎改效率高太多，尤其当你不是专业设计师时，它相当于随身带了个位审美的搭档。

## 04 它默认守着五条设计铁律

技能规范里写死了五条：克制（别过度装饰，留白即设计）、一致（全站统一字号间距圆角配色变量）、响应式（移动端优先）、可访问（对比度达标、可聚焦）、真实内容（用贴近业务的占位文案，别给我整段 lorem ipsum）。

这五条是很多新手页面翻车的地方。它替你把着关，出来的东西起码不土。你真要突破，再手动改。这五条不是束缚，是底线，保你出来的东西起码专业、不翻车。

## 05 一句需求，HTML 直接能预览

回到开头那句。你发完需求，WorkBuddy 输出可直接预览的 HTML，并自动套用上面那些原则。你可以当场在预览面板里看效果，不满意就追一句让它调。

我一般会让它先出三四个风格变体，挑一个顺眼的再细化，比死磕一个版本强。生成式设计的好处就是试错成本几乎为零，多试不亏。

如果你要嵌进这个文档站（它本身 VitePress 构建），可以把片段放 .vitepress/theme/ 自定义，或用 iframe 引独立页面。扩展玩法，后面进阶篇再聊。
