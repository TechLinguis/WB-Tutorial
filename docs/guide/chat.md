# 对话框不只是打字的地方：WorkBuddy 把它变成了指挥中心

很多人用 AI 工具，眼睛只盯着中间那块输入框，打完字等回复。等真上手 WorkBuddy，才发现它把整个界面拆成了三块，每一块都藏着提高你效率的开关。不把这些摸熟，等于开了跑车只用来买菜。

## 01 三块区域，看懂界面就不慌

WorkBuddy 桌面端界面通常分三块：

- 左侧栏：会话列表、技能、连接器、专家中心的入口，相当于你的工具箱。
- 中间区：当前对话的消息流和输入框，主战场。
- 右侧栏：本页目录、文件预览、运行详情，看成果和过程的地方。

记住这个格局，后面所有操作都有归属，不会像无头苍蝇。

## 02 消息流里那些"折叠"的东西，才是精华

每条消息长这样：你输入文字或带文件，WorkBuddy 思考并调工具，最后甩出结论加文件卡片。

重点在中间那层。一个复杂任务它会调几十次工具，默认全给你折叠了，只突出最终结果。新手容易以为"它怎么一下就出结果了"，其实底下跑了老长一串。想学、想排查，点"展开"就能看每一步调用细节。我建议第一次跑复杂任务时一定点开看看，你会发现 AI 干活的逻辑，比想象中透明。

![WorkBuddy 对话界面](/official-shot-conversation-1.png)

## 03 输入框藏着三个不为人知的开关

别把输入框当记事本。它还能：

- 拖文件或图片进去，直接当附件发。
- 用 @ 提及，快速喊某个技能或专家出来干活。
- 输入 / 触发斜杠命令，比如 /commit 提交代码、/review-pr 审 PR。

最后这个很多人不知道。装了技能就有对应的斜杠命令，敲个 / 全出来了。比起翻菜单，这招快十倍。

## 04 产物长这样：文件卡片一甩，直接能看能下

WorkBuddy 生成的不是一段聊天文字就完了。报告（PDF、Word、Excel、PPTX）、网页（HTML 自动开预览）、图片视频甚至 3D 模型，都会以"文件卡片"的形式甩出来，能看能下。

HTML 还会自动弹预览面板，不用你另存再打开。这点对做网页、做原型的人简直救命。工作区内的文件随便预览下载；想把电脑别处的文件传回小程序，记得开那个回传开关（回头看[安装与登录](/guide/installation)）。

![WorkBuddy 对话界面](/official-shot-conversation-2.png)

## 05 左栏五个入口，别只拿来聊天

左侧栏才是真正的控制中枢：会话管理历史、技能安装管理、连接器配授权、专家进中心、自动化建定时任务。

大多数人进来只点"新建对话"，剩下四个入口从来没点过。那等于买了智能手机只用来打电话。技能能扩能力，连接器能接业务系统，自动化能让你睡觉的时候 AI 还在干活。这些后面都会讲，先记住：左栏不是装饰。

右边那栏也别忽略。文档类任务它会列出本页目录，长文一键跳转；跑任务时还能看运行详情，哪一步卡了、调了什么命令，全摊在那。真出了问题先翻右栏，比在聊天记录里大海捞针快得多。
