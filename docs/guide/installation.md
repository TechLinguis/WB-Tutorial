# 装 WorkBuddy 别去百度搜：这一步错了，你的桌面文件可能裸奔

先泼盆冷水。很多人装软件的第一反应是打开搜索引擎，输入名字，点第一个链接，下载，下一步下一步。对付普通工具没毛病，但装 WorkBuddy 这么干，你可能把自家桌面的文件权限，顺手交给了来路不明的安装包。

WorkBuddy 是个能直接读写你电脑文件、跑命令的 AI 办公搭子。它越强，装错渠道的代价就越大。所以这篇不讲花活，只把"怎么安全地装好、登好、用好"这件事讲透。

## 01 先看清：你要在哪个平台用

别急着下载，先对号入座。

- Windows 和 macOS 装桌面端，这是完整能力的入口，文件操作、命令执行、本地构建都靠它。
- 手机端用的是小程序，不负责干重活，但能随时对话、收通知、看产物。

一句话：正经干活在桌面，碎片时间在小程序，两个端同一个账号打通。

## 02 三步装好桌面端，别去第三方网盘下载

步骤比装微信还简单：

第一步，从官方渠道下对应系统的安装包。第二步，双击运行，按提示走完。第三步，启动软件，进登录界面。

这里必须划重点：WorkBuddy 只走官方渠道分发。它不会通过什么网盘链接、社交私信、群里发的压缩包给你发客户端。凡是这类来源，一律当钓鱼处理。我见过太多人图省事从小网盘下"破解版"，结果装回去的是带料的东西。官方的又不要钱，何必冒这个险。

## 03 登录后，你的"云端画像"自动跟着你跑

用账号登录，不只是为了进门。登录之后，你的云端画像会自动同步，你在 A 电脑上装好的技能、连好的连接器，换台设备还在；你设的自动化任务，能在后台持续跑，不用一直开着页面。

这点对经常换设备的人太友好了。以前换个电脑，环境得重新配一遍，现在登录即同步，等于把你的工作习惯装进口袋。

![WorkBuddy 新建项目界面](/official-shot-quickstart.png)

## 04 桌面干重活，手机收通知：两个端怎么配合

这俩不是重复造轮子，是分工。

桌面端负责重活：读文件、跑命令、本地构建，这些吃性能的它来。小程序负责轻活：随时提问、查看产物、接收提醒。你在地铁上收到一条自动化跑完的通知，点开就能看结果，不用守着电脑。

![WorkBuddy 小程序官方二维码](/official-miniprogram.png)

有个开关值得记一下：如果你想让 WorkBuddy 把电脑上桌面、下载目录里的文件传回小程序，得在"小程序连接设置"里打开"产物回传到小程序"。不开的话，它只能交付工作区内的文件。很多新手卡在这一步，以为传不出去是 bug，其实是没开开关。

## 05 装完别急着用，先发这句话验明正身

装好登录完，别一头扎进任务里。先在输入框发一句：

> 你好，请告诉我你现在可用的运行时版本。

它会回报当前的 Node、Python 等运行时信息。能正常回，说明环境是好的，后面放手干就行。这步就像新车先试发动机，三十秒，省得后面出问题不知道是车的问题还是路的问题。
